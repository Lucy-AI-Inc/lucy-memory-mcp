# Security policy

## Supported versions

Until the first tagged release, security fixes are applied to the current `main` branch. After releases begin, this table will list the maintained versions.

## Report privately

Please use [GitHub private vulnerability reporting](https://github.com/Lucy-AI-Inc/lucy-memory-mcp/security/advisories/new) for suspected vulnerabilities.

Do not open a public issue for an unpatched vulnerability. Do not include credentials, customer memory, private logs, or personal data in a report.

Include:

- affected version or commit;
- impact and prerequisites;
- minimal reproduction steps;
- whether a credential or customer environment may be affected;
- suggested remediation, if known.

For non-sensitive bugs and documentation problems, use the public [issue tracker](https://github.com/Lucy-AI-Inc/lucy-memory-mcp/issues).

Repository maintainers should enable GitHub private vulnerability reporting before making the repository public.
